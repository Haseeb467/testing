User Workflow & Experience

Prompt Input UI

  • Hero-level input accepting natural language like “mujhe portfolio site chahiye”.
  • Optional structured controls for theme, palette, components.
  • Validate prompts, track rate limits, and persist history per account.

Split Workspace

  • Left: live preview iframe streaming Sandpack/Next runtime.
  • Right: Monaco or CodeMirror tabs for frontend, backend, and config files.
  • Diff view, auto-format, and instructions overlay for generated components.

Deploy & Export

  • Download ZIP, deploy to Vercel/Netlify, or save to user library.
  • Webhook triggered deploys with Git metadata.
  • Shareable preview links with password protection.

Backend & Generation Engine

API Layer

  • Next.js API routes or Express service at /api/generate.
  • Validation, auth, rate limiting (Upstash Redis), and observability hooks.
  • Streaming updates for long-running generation jobs.

Template Library

  • Opinionated layouts: landing, blog, ecommerce, dashboard.
  • Component metadata for hero, CTA, pricing, testimonials, CRUD tables.
  • TypeScript + Tailwind baseline with accessible variants.

Prompt Parsing

  • LLM-powered parser fills template slots (colors, imagery, data models).
  • Generates Prisma schema, API routes, seed scripts, and fixture data.
  • ESLint/Prettier/tsc validation before exposing code to user.

Live Preview Pipeline

In-browser preview

  • Sandboxed iframe running Sandpack or custom Next mini-runtime.
  • Hot reload connection to editor for instant updates.
  • Secure capability-based messaging to prevent escapes.

On-demand deploys

  • Vercel/Netlify/Cloudflare deploy hooks triggered from generated repo.
  • Temporary git tree pushes for preview builds.
  • Edge/serverless adapters for SSR + API endpoints.

Backend simulation

  • Mock data or SQLite bundle for Prisma-based APIs.
  • Secrets vault for third-party integrations.
  • Optional BullMQ queue for heavy compilation tasks.

Embedded Code Editor

IDE Experience

  • Monaco editor with TS IntelliSense, refactor tools, and diagnostics.
  • File tree exposing pages/, app/, components/, lib/, api/.
  • Command palette for running ESLint, tests, or AI tweaks.

Hot reload bridge

  • Editor changes send patches via service worker to preview runtime.
  • Inline errors shown both in editor gutter and preview overlay.
  • Replayable patch history for undo/redo beyond single session.

Auth, Billing & Limits

Authentication

  • Clerk/Auth0/Supabase Auth with OAuth + passwordless.
  • Org workspaces, role-based permissions, and audit logs.
  • Secure storage of generated assets per workspace.

Billing

  • Stripe subscriptions with usage-based add-ons.
  • Credits for generation minutes, preview runtime, deployments.
  • In-app upgrade prompts when quota near limit.

Quota & Safety

  • Upstash Redis based rate limiting per user/tier.
  • Content moderation + code sandboxing for untrusted input.
  • Watermark or read-only previews for free tier.

AI Enhancements

Prompt-to-code

  • OpenAI/Anthropic models orchestrated via LangChain-style agents.
  • System prompts enforce coding conventions and template usage.
  • Chain-of-thought evaluation before writing to filesystem.

Design-to-code

  • Figma URL ingestion plus screenshot upload with vision parsing.
  • Component detection mapped to internal template registry.
  • Generates responsive variants + Tailwind tokens.

Guided tweaks

  • Chat-based assistant that applies patches directly to repo.
  • Declarative instructions like “button ka color change karo”.
  • Undoable patch queue with human-in-the-loop approvals.

DevOps & Observability

Repo Structure

  • Turbo/PNPM monorepo with apps/web, apps/preview-runner, packages/templates.
  • Shared UI kit, schema package, and codegen utilities.
  • Feature-flagged releases via LaunchDarkly or DB flags.

Observability

  • OpenTelemetry traces piped to DataDog/Sentry.
  • Structured logging for generation steps and deployment hooks.
  • Alerting on model failures, build errors, quota abuse.

Security

  • Run user code in isolated containers with egress controls.
  • Secrets broker for API keys + short-lived credentials.
  • Nightly dependency scanning and SBOM exports.
